# HuggingFace-AI-Projects
Collection of AI projects built using Hugging Face Transformers, Diffusers, Gradio, and PyTorch.

A collection of **7 AI projects** built using **Hugging Face Transformers**, **Diffusers**, **Stable Diffusion**, **Stable Audio**, **Gradio**, and **PyTorch**. These projects demonstrate practical applications of **Natural Language Processing (NLP)**, **Computer Vision (CV)**, **Generative AI**, and **Multimodal AI**.

This repository contains hands-on implementations of:

- 🖼️ Text-to-Image Generation

## 1️⃣ Text-to-Image Generation using Stable Diffusion v1.4

Generate AI images from natural language prompts using Stable Diffusion v1.4.

**Key Features**
- Text-to-Image Generation
- Prompt Engineering
- High-quality Image Synthesis

**Tasks Covered**
- Sentiment Analysis
- Text Classification
- Translation
- Summarization
- Question Answering
- Text Generation

## 3️⃣ Image-to-Image Generation

Transform an input image into a new AI-generated image using diffusion models.

**Key Features**
- Image Transformation

- AI-based Image Generation

Generate realistic images from text prompts using Stable Diffusion v1.5.

- Fast Inference

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/HuggingFace-AI-Projects.git
```

Navigate to the repository:

```bash
cd HuggingFace-AI-Projects
```

Install the required packages:

```bash
pip install -r requirements.txt
```

# ▶️ How to Run

1. Open any project folder.
2. Launch the Jupyter Notebook.
3. Run all cells sequentially.
4. Modify prompts or inputs as required.
5. Generate images, audio, or NLP outputs.
