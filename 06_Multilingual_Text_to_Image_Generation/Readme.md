# Multilingual Text-to-Image Generation

## 📌 Overview

This project translates prompts from multiple languages into English and generates AI images using Stable Diffusion.

---

## 🌍 Supported Languages

- English
- Hindi
- Marathi
- Telugu
- Tamil
- Bengali
- Punjabi
- Gujarati
- Kannada
- Malayalam
- Odia

---

## ✨ Features

- Automatic Translation
- Multilingual Prompt Support
- AI Image Generation
- Cross-Language Prompt Processing

---

## 🛠️ Technologies Used

- Python
- Deep Translator / Google Translator
- Hugging Face Diffusers
- Stable Diffusion
- PyTorch

---
