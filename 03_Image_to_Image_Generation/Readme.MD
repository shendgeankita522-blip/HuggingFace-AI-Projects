# Image-to-Image Generation

## 📌 Overview

This project transforms an input image into a new AI-generated image using Stable Diffusion Image-to-Image models.

---

## Features

- Image Transformation
- AI Image Editing
- Diffusion Models

---

## Technologies Used

- Python
- PyTorch
- Diffusers
- Pillow

---

## How to Run

1. Upload an image.
2. Provide a prompt.
3. Generate the transformed image.
