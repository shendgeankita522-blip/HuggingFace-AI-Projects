# Text-to-Image Generation using Stable Diffusion v1.4

## 📌 Overview

This project generates AI images from natural language prompts using the Stable Diffusion v1.4 model from Hugging Face Diffusers.

---

## Features

- Text-to-Image Generation
- Prompt-based Image Synthesis
- Hugging Face Diffusers
- PyTorch Implementation

---

## Technologies Used

- Python
- PyTorch
- Hugging Face Diffusers
- Stable Diffusion v1.4

---

## Example Prompt

```
A beautiful sunset over the mountains with a lake.
```

---

## How to Run

1. Install dependencies.
2. Open the notebook.
3. Run all cells.
4. Enter your prompt.
5. Generate the image.
